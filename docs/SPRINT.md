# Очерёдность P0/P1/P2

P0 реализовано: runnable Next app,503 records, screening/search/pagination,3 annual research models, DCF/reverse/scenarios, local watchlist, compare, standalone brief, contest gate, immutable snapshot, XLSX/PPTX, unit/browser checks.

P0 остаётся по данным/инфраструктуре: лицензированный актуальный EOD feed, quarterly/TTM refresh, active listings/eligibility, OHLCV/entry/exit, reviewed Buy,  безопасный доступ жюри.

До дедлайна приоритет имеют эти пробелы, а не дополнительные функции. P1 после доказанного P0: evidence-backed LLM red team, shared workspace, версионирование тезисов. P2: point-in-time backtest, уведомления, банковские модели. ML/платежи/торговые ордера не входят в текущий срез.

Завершено дополнительно: согласованная Supabase mirror_x schema, Auth, private cloud research/models, DB screening/pagination, remote RLS и12 Auth/API проверок. Тарифы не повышались.
