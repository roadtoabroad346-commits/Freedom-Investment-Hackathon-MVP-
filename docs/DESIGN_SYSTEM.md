# Визуальная система

Светлая институциональная исследовательская среда. Navy#17253D, paper#F7F9FC, emerald#147D55, amber для неопределённости. Семантические CSS variables, табличные цифры, один набор SVG Lucide. Без декоративных stock charts с вымышленной историей.

Рабочая область: боковая навигация desktop, компактная верхняя mobile. Таблица компаний на390px превращается в карточки. Сложные финансовые таблицы имеют локальный scroll-container, не растягивают страницу. Sliders имеют visible labels, keyboard access, output и описания. Цвет не единственный носитель статуса: PASS/REVIEW/UNDATED даны текстом.

Использованы правила доступности и адаптивности UI/UX Pro Max. Поисковый design-system script облачного skill не установлен локально; палитра взята из явного ТЗ и общих правил skill, а не из несуществующего результата базы. Отдельного dark mode нет и его проверка не заявляется.
