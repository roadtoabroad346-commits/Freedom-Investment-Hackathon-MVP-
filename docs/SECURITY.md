# Безопасность и границы

Публичные endpoints только читают импортированные данные и статические экспорты. Нет API записи заметок/портфелей, выдачи service-role или доступа к БД. URL-параметры screening валидируются Zod, размер страницы ограничен100. Экспорт допускает только xlsx/pptx; путь берётся из фиксированного enum, а не произвольного пользовательского имени. Неподдерживаемый ticker даёт404.

React экранирует текст заметок. Нет dangerouslySetInnerHTML, выполнения текста отчётов, LLM tools или внешних действий из содержимого файлов. Входные документы считаются данными. Нет брокерских API и реальных ордеров.

Заголовки: nosniff, X-Frame-Options:DENY, Referrer-Policy и ограничение camera/microphone/geolocation. CSP и централизованный rate limiter не заявлены как готовые; при публичном запуске настроить platform rate limits. Экспорт строится заранее, поэтому запрос не запускает дорогостоящую генерацию.

localStorage не является безопасным серверным workspace. Это явно подписанное локальное сохранение. В него нельзя записывать секреты. Телеметрия приложения не включена.

Если подключается Supabase: только целевой проект, RLS на всех exposed tables, minimal GRANT, ownership policies с USING/WITH CHECK, auth.uid(), без user_metadata-авторизации, без service-role в клиенте, security_invoker для views. SQL-кандидат подготовлен, но не применён и не протестирован удалённо.

Зависимости зафиксированы. Уязвимые первоначальные версии Zod/csv-parse/PptxGenJS обновлены, uuid/image-size переопределены на исправленные версии; совместимость проверена сборкой и реальной генерацией файлов. Результат audit на дату проверки указан в QA.
