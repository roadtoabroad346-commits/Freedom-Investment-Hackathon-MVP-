# Screening v1

1. Весь загруженный universe. Поиск ticker/name, отрасль, максимальный положительный P/E, минимум market cap, положительная EBITDA, наличие датированной цены.
2. Сравнимость: группа внутри указанной отрасли, минимум 5 записей с положительными P/E, EBITDA и капитализацией. Банки, страховщики, consumer finance, capital markets, REIT и mortgage исключены из общего score.
3. Score = 60% обратный процентиль P/E + 40% процентиль EBITDA / market cap. Ties получают среднюю позицию. Результат ограничен процентильной шкалой, поэтому выброс не получает неограниченный вклад. Версия `sector-value-v1`.
4. Неполные входы → score=null, конкретная причина; никакого score=50. Нет добавочного балла за отсутствие данных.
5. Сортировка стабильна по ticker при равенстве, страницы не дублируют записи. Ограничение API pageSize <=100, page<=1000.

Это минимальный двухфакторный рейтинг, а не полный семифакторный рейтинг качества. EBITDA / equity market cap — не FCF yield, не EV/EBITDA. Отрасли исходного набора иногда узкие, поэтому N/A ожидаем. Дата общего набора неизвестна: результаты нельзя интерпретировать как актуальный список недооценённых акций.
